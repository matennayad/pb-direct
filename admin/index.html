ניהול הקטלוג

המאגר עדיין ציבורי: מחירים ושמות מקור שתשמרו כאן יהיו גלויים לכל מי שנכנס למאגר ב-GitHub. כדאי להעביר את המאגר לפרטי לפני שמזינים מחירים אמיתיים.

כניסה לניהול

הדף קורא וכותב את נתוני הקטלוג ישירות במאגר ב-GitHub. כדי להיכנס צריך טוקן גישה (Fine-grained token) עם הרשאת Contents: Read and write למאגר הזה בלבד. הטוקן נשמר רק בדפדפן הזה.

הגדרות מתקדמות (בדרך כלל לא צריך לשנות)

לאיזה מאגר ב-GitHub הדף מתחבר: שם המשתמש, שם המאגר והענף שבו שמורים נתוני הקטלוג. הערכים כבר ממולאים נכון.
